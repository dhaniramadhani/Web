# Wireframe SIMPUS-Mini

## 1. Skema Navigasi Sistem

```text
                         +------------------+
                         |      LOGIN       |
                         +---------+--------+
                                   |
                                   v
                         +------------------+
                         |    DASHBOARD     |
                         +---------+--------+
                                   |
             +---------------------+---------------------+
             |                     |                     |
             v                     v                     v
   +------------------+   +------------------+   +------------------+
   |   PEMINJAMAN     |   |  PENGEMBALIAN   |   |     RIWAYAT      |
   +--------+---------+   +--------+---------+   +------------------+
            |                      |
            v                      v
   +------------------+   +------------------+
   | PILIH ANGGOTA    |   | CARI PEMINJAMAN |
   +--------+---------+   +--------+---------+
            |                      |
            v                      v
   +------------------+   +------------------+
   |    PILIH BUKU    |   | KONFIRMASI DATA |
   +--------+---------+   +--------+---------+
            |                      |
            v                      v
   +------------------+   +------------------+
   | SIMPAN PINJAMAN  |   | KEMBALIKAN BUKU |
   +--------+---------+   +--------+---------+
            |                      |
            +-----------+----------+
                        |
                        v
               +------------------+
               |     RIWAYAT      |
               +------------------+
```

Skema di atas menunjukkan alur utama penggunaan sistem perpustakaan. Petugas melakukan login terlebih dahulu, kemudian masuk ke dashboard. Dari dashboard, petugas dapat memilih menu peminjaman, pengembalian, atau melihat riwayat transaksi.

## Kesimpulan

Wireframe SIMPUS-Mini dirancang untuk memberikan gambaran awal antarmuka sebelum sistem dikembangkan ke tahap implementasi.

Alur utama sistem dimulai dari proses login petugas. Setelah berhasil login, petugas masuk ke dashboard dan dapat mengakses fitur peminjaman, pengembalian, serta riwayat transaksi.

Wireframe ini akan digunakan sebagai acuan dalam pembuatan tampilan dan pengembangan fitur pada jobsheet berikutnya.
